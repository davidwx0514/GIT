# 小步 · 初一数学错题本

一个无需安装依赖的静态网页版错题本。支持错题照片、知识点与错因分类、答案折叠复习、掌握状态、编辑删除、搜索和 JSON 备份。

## 本地启动

在仓库根目录运行：

```sh
python3 -m http.server 8000 --directory app --bind 0.0.0.0
```

通过运行环境提供的 HTTP 地址打开。手机或平板访问需要把此目录部署到支持 HTTPS 的静态网站托管服务。没有后端、账户或跨设备自动同步；每个浏览器独立保存数据，建议定期导出备份，再在其他设备导入。照片会压缩到最长边 1400 像素；浏览器存储空间有限，保存失败会提示。

本地 HTTP 或正式 HTTPS 下使用现代浏览器。图片识别和 AI 讲解尚未实现。照片与错题保存在浏览器，不发送到服务端。字体使用在线 Google Fonts，加载失败会使用系统字体。
